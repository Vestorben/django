# Фактические результаты проверки

Среда: Python 3.12.14, Django 5.2.19, SQLAlchemy 2.0.57, psycopg 3.3.8.

- `python -m unittest -v`: **27 тестов, все пройдены**. Использовались отдельные временные SQLite-базы в памяти для Django и SQLAlchemy, без подключения к рабочей базе.
- `python manage.py check`: **ошибок не обнаружено**.
- `python -m compileall -q unity`: все Python-файлы успешно скомпилированы (команда запускалась из родительского каталога).
- Django test client успешно отрисовал афишу, страницу события, вход, регистрацию, отменённое событие, личный кабинет, форму отзыва, страницу управления, форму события и список участников. Импорты, имена маршрутов и ссылки шаблонов согласованы.
- Проверены обязательные поля, категории, вместимость, порядок дат и московский часовой пояс; регистрация и хеширование пароля; права гостя, участника и администратора, включая запрет управления для `is_staff` без `is_superuser`.
- Проверены повторная запись, отсутствие мест, запрет записи на начавшееся/прошедшее/отменённое событие, отмена только своей заявки до начала, сохранение заявок при отмене организатором, группы личного кабинета.
- Проверены создание, изменение и удаление своего отзыва; запреты для чужих отзывов, незаписанных пользователей и незавершённых/отменённых событий; диапазон оценок и длина текста.
- Проверены POST для изменяющих действий, CSRF, экранирование HTML, закрытый список участников и повторный запуск демонстрационного наполнения без дублей.

**Ограничения проверки:** PostgreSQL 17 недоступен в этой среде. Рабочее подключение через psycopg, миграции Django, создание SQLAlchemy-таблиц и совместная работа ORM на PostgreSQL фактически не запускались. SQLite-тесты не заменяют эту интеграционную проверку.

Запуск Chromium был предпринят, но завершился ошибкой среды: запрещено создание системного сокета. Визуальная проверка страниц в браузере и проверка адаптивности на реальном экране **не выполнены**. В CSS предусмотрены макеты для широкого экрана и телефона.
